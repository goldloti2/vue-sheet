# 編輯器

編輯器是於本機執行的網頁 App，用來修改專案的檔案，並即時預覽修改的結果。編輯器只讀寫專案的檔案，不修改框架的檔案、Sheet 的內容與部署。專案與框架的範圍見根目錄 [AGENTS.md](../../AGENTS.md) 的「框架與專案」。

## 啟動

1. 於 `vue-build/` 執行 `npm install`。編輯器的預覽與檢查使用 `vue-build/` 中的套件。
2. 於 `editor/` 執行 `npm install`。
3. 於 `editor/` 執行 `npm run editor`。
4. 以瀏覽器開啟終端機顯示的網址。

編輯器開啟時，顯示 `schemas` 中的第一張表。

## 版面

| 區域 | 位置 | 用途 |
| --- | --- | --- |
| **導覽** | 左側 | 依類型列出專案的檔案。點選檔案即在檔案區開啟 |
| **檔案區** | 中間 | 一次顯示一個檔案。有表單的檔案可以切換表單與文字編輯器 |
| **預覽** | 右側 | 以 vue-build 的 dev server 顯示 App |
| **下方面板** | 檔案區的下方 | 問題、建置、欄位查詢與控制台 |

導覽、預覽與下方面板皆可收合。重新整理頁面後，三者皆為展開。

### 導覽

導覽的左邊為各組的圖示，右邊列出所選的組的檔案與頁面。

| 組 | 檔案與頁面 |
| --- | --- |
| **表** | 總覽（`schema/index.ts`），以及各表的 schema。表以 `tableLabel` 與代號顯示 |
| **動作** | 總覽（`composables/actions/index.ts`），以及各表的 `use表名Actions` |
| **頁面** | `pages/` 中的檔案。依序為登入頁、首頁、各表的資料夾、其他頁面 |
| **導覽** | 導覽列（`config/navigation.ts`） |
| **設定** | 後端表頭（`apps-script/Config.gs`），以及 App 設定（`config/app.ts` 與 `Config.gs` 的各項設定） |
| **測試資料** | 總覽（`services/mock/tables.ts`），以及 `mock/` 中的 CSV。CSV 以對應的表名與代號顯示 |

- 表、動作與頁面中各表的資料夾，依 `schemas` 的順序排列。沒有登記的表排在最後。
- 只有一個檔案或頁面的組，點選圖示時一併開啟該檔案或頁面。
- 組中有未儲存的檔案時，圖示加上圓點。頁面的任一個檔案未儲存時，頁面加上圓點。
- 從其他地方開啟檔案時，導覽切換至該檔案所在的組，並展開檔案所在的資料夾。
- 收合時只留各組的圖示。點選任一個圖示即展開。

### 檔案區

- 表的 schema、表的總覽、測試資料的總覽與 CSV 有表單。右上的開關切換表單與文字編輯器。
- `Config.gs`、`config/app.ts` 與 `config/navigation.ts` 只有表單。`app.ts` 只在「App 設定」中修改。從問題分頁開啟這三個檔案時，開啟表單，並提示以其他編輯器修改該行。
- 其他檔案只有文字編輯器。
- 工具列的標題為檔案或頁面於導覽中的位置，例如「表/訂單」「設定/App 設定」。不在導覽中的檔案以路徑為標題。
- 文字編輯器為 CodeMirror。`vue-build/src/` 中的 `.ts` 與 `.vue` 檔有即時的錯誤標示與補全。補全依欄位的 key 比對。
- 切換檔案時，未儲存的修改、游標與捲動的位置皆保留。

### 預覽

- **資料來源**：

  | 名稱 | 資料 |
  | --- | --- |
  | 本地測試 | 假後端，讀取 `vue-build/mock/` 中的 CSV。修改只留在記憶體中 |
  | 線上測試 | `vue-build/.env.fake.local` 中 `VITE_APPS_SCRIPT_URL` 指向的 Sheet。沒有此檔或此設定時無法選取 |
  | 線上正式 | `vue-build/.env` 中 `VITE_APPS_SCRIPT_URL` 指向的 Sheet。沒有此設定時無法選取。選取時，預覽上方顯示修改會寫入正式的 Sheet |

- 切換資料來源時，預覽的 dev server 重新啟動。
- 預覽有手機版與電腦版。手機版整頁縮小至完整放入預覽中。選取電腦版時，預覽改為全視窗。按 Esc 或「結束全視窗」即結束全視窗，並改回手機版。
- 重新整理時，控制台一併清空。
- 預覽顯示未儲存的內容（見「儲存」）。
- 收合時只留展開的按鈕。預覽的頁面保留，不重新載入。

### 下方面板

| 分頁 | 內容 |
| --- | --- |
| **問題** | 即時檢查、ESLint、vue-tsc 與預覽的 Vite 錯誤。點選一個問題即開啟該檔案，並移至該行 |
| **建置** | 「vite build」按鈕與建置的輸出 |
| **欄位查詢** | 左邊列出各表，右邊列出所選的表的欄位：key、標籤、型別，以及 `ref` 欄位指向的表。雙擊一個欄位，把它的 key 插入最後聚焦的文字編輯器的游標處 |
| **控制台** | 預覽頁面的 `console.warn`、`console.error` 與未捕捉的錯誤，以及預覽的 dev server 的輸出 |

- 問題與控制台的分頁上顯示項目的數量。
- 收合時只留分頁列。點選任一個分頁即展開。

## 儲存

- 一般的修改只留在記憶體中。按「儲存」或 Ctrl+S（macOS 為 Cmd+S）才寫入目前的檔案。「全部儲存」寫入所有未儲存的檔案。
- 「放棄修改」改回檔案的內容。
- 開啟頁面時，「儲存」與「放棄修改」涵蓋頁面的所有檔案。
- 有未儲存的修改時，關閉瀏覽器的分頁前先確認。
- 預覽使用未儲存的內容。
  - 文字編輯器的修改，於焦點離開或切換檔案時更新預覽。
  - 表單中的文字輸入，於送出時更新預覽。小視窗中的修改，於關閉時更新預覽。勾選與選單的修改，於停止修改後更新預覽。
  - 儲存或放棄修改後，預覽改回檔案的內容。
  - schema 檔有欄位的結構修改時，預覽不更新（見 [forms.md](forms.md) 的「欄位的結構修改」）。
- 寫入時，編輯器以 ESLint 修正格式。
- 檔案已在別處修改時，編輯器不寫入，並保留畫面上的修改。再儲存一次即覆蓋別處的修改。按「放棄修改」改為顯示檔案目前的內容。
- 以下操作立即寫入，不經過「儲存」：
  - 新增表與刪除表，包括 `Config.gs` 中的登記
  - 測試資料的總覽中的「建立 CSV」
- 立即寫入的操作所涉及的檔案有未儲存的修改時，編輯器不執行，並請使用者先儲存或放棄修改。
