# 編輯器的表單

各種表單與檔案的對應。有文字編輯器的檔案，表單與文字編輯器修改同一份記憶體中的內容。表單無法處理的寫法，以程式碼顯示，或請使用者以文字編輯器修改。儲存的規則見 [README.md](README.md) 的「儲存」，服務端的修改方式見 [architecture.md](architecture.md) 的「schema 檔的修改」。

| 檔案 | 表單 |
| --- | --- |
| 各表的 schema | 表的表單 |
| `schema/index.ts` | 表的總覽 |
| `services/mock/tables.ts` | 測試資料的總覽 |
| `mock/` 中的 CSV | CSV 的表格 |
| `apps-script/Config.gs` | 後端表頭、App 設定 |
| `vue-build/src/config/app.ts` | App 設定 |

- `Config.gs` 與 `app.ts` 只有表單，沒有文字編輯器。表單無法處理的寫法，須以其他編輯器修改。
- 編輯器只修改 `app.ts` 中各設定項的值，不修改型別、註解與其他程式碼。

## 表的表單

上方為表的設定，下方分為「欄位」「搜尋與排序」「條件式格式」三個分頁。虛擬表另有「規則」分頁，位於「欄位」之後。

schema 有 `rules` 時為虛擬表。虛擬表沒有的設定不顯示：主鍵字首、Sheet 表頭、主鍵、必填、初始值、驗證與 `formOrder`。

### 表的設定

- **表名**：`tableLabel`。
- **主鍵字首**：`newId: prefixedId('字首')` 中的字首。
  - 留空時刪除 `newId`，主鍵改為必填。
  - 填入時補上 `prefixedId` 的匯入。
  - `newId` 為其他寫法時，以程式碼顯示。

### 欄位

- 一列一個欄位。真實欄位在前，虛擬欄位在後。虛擬欄位的 key 以主色顯示。
- 以左邊的把手拖曳，可以調整欄位的順序。拖曳只在同一種欄位之中移動。
- 各欄：

  | 欄 | 設定 |
  | --- | --- |
  | **key** | 欄位的 key。修改見「欄位的結構修改」 |
  | **標籤** | `label`。修改見「欄位的結構修改」 |
  | **Sheet 表頭** | `sheetHeader`。留空時刪除此設定 |
  | **型別** | 點選時開啟型別的小視窗 |
  | **主鍵** | `idColumn`。只能選取值為字串的真實欄位 |
  | **稱呼** | `labelColumn`。再點一次即取消 |
  | **必填** | `required` |
  | **初始值、驗證、顯示條件、計算方式** | `default`、`validate`、`showIf`、`value`。以程式碼輸入 |

- 只屬於另一種欄位的設定會停用。真實欄位停用計算方式。虛擬欄位停用 Sheet 表頭、必填、初始值與驗證。
- 不是以物件字面值寫成的欄位，只顯示「以程式碼寫成」，須以文字編輯器修改。

### 型別的小視窗

- 選取型別，並設定該型別專屬的設定，例如 `options`、`min`、`refTable`。型別的選單下方顯示 `types.ts` 中此型別的說明。
- 虛擬表的欄位與虛擬欄位的 ref 只有 `refTable`，不顯示 `onDelete`、`onEmpty`、`refSort` 與 `allowCreate`。
- `refTable` 以選單列出現有的表。真實表的真實欄位不列出虛擬表。
- 小視窗中的修改立即寫入記憶體中的內容。關閉時才更新預覽。
- 「取消」改回開啟時的內容。「完成」、點選小視窗外或按 Esc 皆保留修改。

### 程式碼的輸入

- 函數與其他無法以表單輸入的設定，以一行的方框顯示原文。點選時開啟程式碼的對話框。
- 對話框的標題為表名與設定的名稱。欄位的設定另外寫出欄位的標籤，例如「訂單/初始值：價格」。沒有標籤時為 key。
- `types.ts` 中有此設定的說明時，說明顯示於編輯區的上方。
- 上半為 CodeMirror 的編輯區，有行號、型別檢查與補全。檢查與補全以整個檔案的內容為準。
- 下半為查詢區，目前只有欄位查詢。欄位查詢與下方面板的分頁相同。雙擊一個欄位，把它的 key 插入編輯區的游標處。
- 「完成」寫回並檢查語法。有語法錯誤時，對話框保持開啟並顯示錯誤。
- 「取消」放棄這次的修改。
- 點選對話框外或按 Esc 時，沒有修改即關閉。有修改時先詢問：「返回」回到對話框，「套用並關閉」與「完成」相同。
- 清空內容即刪除該設定。

### 規則

只有虛擬表有此分頁。

- 上方說明規則的作用：來源表的每一列，符合幾條規則就產生幾列。
- 清單一列一條規則，依序顯示序號、來源表的表名與條件的原文。沒有條件時顯示「（每一列）」。
- 規則可以拖曳排序。序號為列的 id 的一部分。
- 「新增規則」加入一條規則，並開啟規則的小視窗。新的規則以第一張真實表為來源表，條件永不成立，沒有填入的值。
- 點選一條規則即開啟規則的小視窗：
  - **來源表**：以選單列出真實表，依 `schemas` 的順序。
  - **條件**：`when`，以程式碼輸入。
  - **各欄位的值**：`columns` 中的每個欄位一列，為 `values` 中的值，以程式碼輸入。清空即刪除該欄的值。
  - 小視窗中的修改立即寫入記憶體中的內容。關閉時才更新預覽。
  - 「刪除規則」刪除這條規則並關閉小視窗。「取消」改回開啟時的內容。「完成」、點選小視窗外或按 Esc 皆保留修改。
- 不是以物件字面值寫成的規則或 `values`，只顯示「以程式碼寫成」，須以文字編輯器修改。

### 搜尋與排序

- 左邊列出五個清單：`searchable`、`sortable`、`detailOrder`、`formOrder`、`defaultSort`。省略的清單與以程式碼寫成的清單，於名稱下方標示。
- 右邊為所選的清單的項目。
  - 項目可以拖曳排序，也可以刪除。
  - 「加入」從尚未列入的欄位中選取。
  - `defaultSort` 的每一項可以切換升冪與降冪。新加入的項目為升冪。
  - 「省略」刪除整個設定。清單省略時，右邊說明框架於省略時的行為。
- 項目以欄位的標籤顯示。

### 條件式格式

- 左邊列出各條規則。每一條以圖示與第一個套用的欄位顯示，並套用規則的顏色。規則可以拖曳排序。
- 「新增規則」加入一條只有必填設定的規則：條件永不成立，沒有套用的欄位。新增後即選取此規則。
- 右邊列出所選的規則的設定，一列一項，最下方為「刪除規則」。
  - 設定的名稱：條件、套用欄位、顏色、粗體、斜體、底線、刪除線、圖示、圖示顏色。其他設定以 `types.ts` 中說明的第一句為名，沒有說明時為設定名。
  - 套用欄位以勾選選取，依欄位的順序寫入。
  - 顏色以色塊選取。色塊的顏色與 vue-build 的主題相同。「不設定」刪除此設定。
  - 圖示從全部的 mdi 圖示中搜尋。選取後寫成 `@mdi/js` 的變數，並補上匯入。

### 設定的輸入方式

型別的小視窗與條件式格式的設定，依 `types.ts` 中設定的型別決定輸入方式。

| 設定的型別 | 輸入方式 |
| --- | --- |
| `boolean` | 勾選框 |
| `number` | 數字 |
| `string` | 文字 |
| 字串字面值的聯集 | 選單。共用色名為色塊 |
| `string[]` | 可增刪的清單 |
| 欄位的 key | 欄位的選單 |
| 欄位的 key 的陣列 | 欄位的勾選 |
| 函數與其他型別 | 程式碼 |

設定目前的值不是對應的寫法時，以程式碼顯示。

## 欄位的結構修改

新增、刪除欄位與修改 key、標籤皆為未儲存的修改。

- **新增欄位**：「新增欄位」開啟小視窗，輸入 key、標籤與型別，並選擇是否為虛擬欄位。輸入時檢查 key 的寫法，以及是否與其他欄位重複。新增後關閉小視窗。
- **刪除欄位**：
  - 同一檔案中引用此欄位的設定一併刪除，例如搜尋與排序、稱呼、條件式格式套用的欄位、規則的 `values` 中此欄位的值。
  - 其他檔案中的引用列於問題分頁。
  - 主鍵的欄位無法刪除。
- **修改 key**：
  - 送出時檢查 key 的寫法，以及是否與其他欄位重複。不可使用時，輸入框改回原值，並顯示原因。
  - 其他檔案中引用此欄位的地方一併修改，包括 `.vue` 檔。這些檔案也是未儲存的修改。
  - 規則的 `values` 中此欄位的屬性名一併修改。
- **修改標籤**：
  - 虛擬欄位、虛擬表的欄位，或已有 Sheet 表頭的欄位，直接修改標籤。
  - 其他欄位的標籤即為 Sheet 的表頭。修改時，小視窗詢問處理方式：
    - 修改 Sheet 的表頭：使用者自行修改 Sheet。有本地測試的 CSV 時，CSV 的表頭一併修改。欄位為主鍵時，小視窗提醒使用者自行修改 `Config.gs` 中此表的 `idColumn`。
    - 保留 Sheet 的表頭：加上原標籤為 Sheet 表頭，只修改畫面上的標籤。

### 連帶的修改

- 修改 key 時改到的其他檔案，以及修改標籤時改到的 CSV，皆記為此 schema 檔連帶的修改。
- schema 檔有欄位的結構修改時，此檔與連帶修改的檔案皆不更新預覽。預覽上方顯示提示。
- **儲存**：要儲存的 schema 檔有欄位的修改時，先顯示確認的小視窗。
  - 小視窗列出各檔的欄位的修改：新增、刪除、key 的改名、表頭與型別的修改。
  - 連帶修改的檔案中，這次不儲存的檔案以導覽中的位置列出，例如「頁面/訂單/列表頁」。
- **放棄修改**：放棄 schema 檔的修改時，連帶的修改由後往前反向執行，把新的值改回舊的值。無法還原的項目以提示列出。
- schema 檔儲存或放棄修改後，連帶的關係即解除。

## 表的總覽

`schema/index.ts` 的 `schemas` 以表格顯示，一列一張表。

- `schemas` 中登記的表依其順序在前。有 schema 檔但沒有登記的表排在最後，以淡色顯示。
- 各欄：
  - **把手**：拖曳以調整 `schemas` 的順序。只有登記的表可以拖曳。導覽中各表的順序隨之改變。
  - **啟用**：打開時登記於 `schemas`，並補上匯入。真實表置於第一張虛擬表之前，虛擬表置於最後。關掉時從 `schemas` 刪除，並刪除不再使用的匯入。其他檔案不受影響。找不到 schema 的變數名時無法打開。
  - **表名**、**代號**
  - **檔案**：schema、動作、頁面、CSV。虛擬表不列出 CSV。點選即開啟該檔案。頁面依序開啟列表頁、`[id]/index.vue`、資料夾中的第一個頁面。
  - **刪除**：開啟刪除表的小視窗。
- 以程式碼寫成的項目，只顯示「以程式碼寫成」，須以文字編輯器修改。
- 「新增表」開啟新增表的小視窗。導覽中「表」的組名旁也有同一個按鈕。

### 新增與刪除表

- **新增表**：輸入表名、代號與主鍵字首，並選擇是否為虛擬表。
  - 代號只能使用英文字母與數字，且第一個字為小寫英文字母。代號不可與現有的表重複。
  - 主鍵字首只能使用大寫英文字母與數字。勾選「虛擬表」時不顯示主鍵字首。
  - 真實表：
    - 編輯器由範本建立 schema、動作與只有表頭的 CSV，並登記於 `schemas` 與測試資料。schema 只留主鍵與稱呼的欄位。
    - 登記於 `schemas` 時，置於第一張虛擬表之前。
    - `Config.gs` 不修改。線上的資料來源讀取新表前，使用者須自行於 `Config.gs` 登記。
  - 虛擬表：
    - 編輯器由虛擬表的範本建立 schema 與動作，並登記於 `schemas` 的最後。
    - schema 只留稱呼的欄位，沒有規則。
    - 虛擬表沒有 CSV，不登記於測試資料與 `Config.gs`。
  - 按「新增」後，欄位停用，直到建立完成。建立成功時，編輯器開啟新表的 schema，再關閉小視窗。建立失敗時，小視窗保留輸入的內容。
- **刪除表**：小視窗以導覽中的位置列出一併刪除的檔案與登記。
  - 檔案：schema、動作、`pages/` 中此表的資料夾、其他表中此表的展開頁、此表的 CSV。
  - 登記：`schemas` 與測試資料中此表的登記。
  - 其他引用此表的地方列於問題分頁，例如其他表的 `refTable` 與導覽的連結。`Config.gs` 中的登記須由使用者自行刪除。
  - 刪除後無法在編輯器中還原。
- 新增表與刪除表皆立即寫入。`schema/index.ts`、`services/mock/tables.ts` 或要刪除的檔案有未儲存的修改時，編輯器不執行。

- 虛擬表沒有 CSV，不列出。

## 後端表頭

開啟 `apps-script/Config.gs` 時顯示此表單。`TABLES` 以表格顯示，一列一張表。

- 各表的順序：
  - 真實表依 `schemas` 的順序在前。沒有登記於 `schemas` 的真實表依代號排在其後。
  - `TABLES` 中沒有對應真實表的項目排在最後。
  - 虛擬表不列出。
- 各欄：
  - **表名**、**代號**
  - **Sheet 分頁名稱**、**ID 欄**：`TABLES` 中此表的 `sheetName` 與 `idColumn`。空白時改回原值。
  - **狀態**：以警告色標示不一致的地方。
  - **按鈕**：「登記」或刪除。
- **沒有登記的表**：以淡色顯示，並提供「登記」按鈕。
  - 登記時，Sheet 分頁名稱為表名，ID 欄為主鍵的表頭。
  - 找不到主鍵的表頭時無法登記。
- **找不到表**：`TABLES` 中有登記，但沒有對應的真實表。狀態標示「找不到表」，並提供刪除按鈕。
- **ID 欄與主鍵的表頭不同**：狀態標示主鍵的表頭。主鍵的表頭為主鍵欄位的 `sheetHeader`，沒有時為 `label`。
- `TABLES` 的順序不影響後端，表單不提供排序。
- 以程式碼寫成的項目，只顯示「以程式碼寫成」，須以其他編輯器修改。

## App 設定

導覽中「設定」組的「App 設定」開啟此頁。此頁同時修改 `vue-build/src/config/app.ts` 與 `apps-script/Config.gs` 的各項設定。

| 區 | 設定 | 檔案 | 輸入方式 |
| --- | --- | --- | --- |
| **App** | **App 名稱**（`appName`） | `app.ts` | 文字，不可空白 |
| | **詳細頁欄位表示**（`detailFieldLayout`） | `app.ts` | 選單。選項為型別列出的值，「左右並排」為 `'side'`，「名稱在上」為 `'stacked'` |
| | **計時推送**（`autoPushDelay`） | `app.ts` | 以秒輸入，大於 0。空白為不啟用，寫入 `null` |
| **登入** | **登入方式**（`authMethod` 與 `AUTH`） | 兩個檔案 | 選單 |
| **後端** | **表頭列號**（`HEADER_ROW`） | `Config.gs` | 1 以上的整數 |
| | **推送排隊上限**（`LOCK_TIMEOUT_MS`） | `Config.gs` | 有其他推送正在寫入時，等待的上限。以秒輸入，大於 0。寫入時寫成「秒數 * 1000」。讀取時，只寫一個數字的寫法以毫秒換算為秒 |

- 登入方式一次寫入兩個檔案：
  - 「不須登入」：`authMethod` 為 `'none'`，`AUTH` 為 `null`。
  - 「密碼」：`authMethod` 為 `'custom'`，`AUTH` 為 `'password'`。
  - 兩者不是同一組時，以警告色標示兩邊目前的值。選擇登入方式後，兩邊一起修改。
  - 任一邊以程式碼寫成或找不到時，無法修改。
- 不符合輸入方式的值不寫入，輸入框改回原值。
- 以程式碼寫成的設定，只顯示「以程式碼寫成」，須以其他編輯器修改。
- 「儲存」與「放棄修改」皆涵蓋兩個檔案。
