# 編輯器的版面數值

編輯器的寬度、高度與時間等數值。各區域的用途見 [README.md](README.md)，各表單見 [forms.md](forms.md)。

---

## 整體

| 項目 | 數值 |
| --- | --- |
| 導覽的寬度 | 316px。收合時為 56px |
| 下方面板的高度 | 220px。收合時只留分頁列 |
| 預覽的寬度 | 手機版縮小後的寬度，加上左右各 16px。收合時為 48px |
| 編輯器的埠 | 3100 |
| 預覽的埠 | 3101 |

---

## 導覽

| 項目 | 數值 |
| --- | --- |
| 各組的圖示列 | 寬 56px |
| 各組的按鈕 | 40px × 40px，間距 4px |
| 檔案的清單 | 寬 260px |
| 清單的標題列 | 高 48px |

---

## 預覽

| 項目 | 數值 |
| --- | --- |
| 手機版的頁面 | 412px × 915px。整頁縮小至完整放入預覽，並置中。不放大 |
| 電腦版的頁面 | 寬 1280px。可用寬度不足時，整頁縮小。可用寬度較寬時，頁面隨之變寬 |
| 工具列 | 高 48px |
| 資料來源的選單 | 寬至多 180px |
| 視窗不夠高時 | 手機版依可用高度縮小，預覽隨之變窄 |

| --- | --- |

## 表單共用

| 項目 | 數值 |
| --- | --- |
| 表格的列 | 高 40px |
| 輸入框 | 高 32px |
| 「新增欄位」與「新增表」按鈕 | 高 32px，字體與輸入框相同 |
| 總覽中的開關 | 縮小為 0.5 倍 |
| 小視窗的寬度 | 新增欄位、新增表、刪除欄位：至多 420px。修改標籤：至多 480px。刪除表、儲存的確認：至多 520px。型別、規則：至多 560px |
