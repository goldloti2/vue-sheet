# DataTable

表格式列表。整頁的列表放進 [ListPage](../page/ListPage.md) 的 `#rows` slot（它一次給整批），也用在 detail 頁內嵌的關聯子表格（一對多同頁顯示），兩種用途同一個元件。`columns` 可以混用真實欄位與 schema `virtualColumns` 的 key，顯示順序照 `columns` 陣列。每列各自算的東西（例如小計）寫成那張表的虛擬欄位，這裡直接用 key 指。

## Usage

```vue
<script lang="ts" setup>
  import DataTable from '@/components/ui/list/DataTable.vue'
</script>

<template>
  <DataTable
    :columns="['欄位1', '虛擬欄位']"
    :row-to="(row) => `/路徑/${row.id}`"
    :rows="rows"
    :show-header="false"
    :schema="__table__Schema"
  />
</template>
```

## Props

| prop | 型別 | 說明 |
| --- | --- | --- |
| `rows` | `readonly Row[]` | **必填** |
| `schema` | `TableSchema` | **必填** |
| `columns` | `string[]?` | 要顯示的欄位 key；省略＝全部真實欄位加全部虛擬欄位 |
| `showHeader` | `boolean?` | 預設 `true` |
| `rowTo` | `((row) => string)?` | 有給才可點擊導覽；不給就是純顯示 |
| `widths` | `Partial<Record<string, 'max' \| 'default' \| 'min'>>?` | 各欄的寬度設定，見下方「欄寬」；沒列到的欄為 `'default'`，省略時全部為 `'default'` |
| `wrap` | `boolean?` | 放不下的格子改為換行，而非截斷；預設 `false`，見下方「欄寬」 |
| `fixed` | `number?` | 橫向捲動時固定於左側的欄數，自第一欄起；預設 `0`，見下方「固定欄」 |

## 欄寬

每欄以三種設定之一決定寬度，預設不換行。一欄的「內容寬」為該欄不換行時最寬的一格，表頭也算在內。

| 設定 | 寬度 | 放不下時 |
| --- | --- | --- |
| `max`（最大） | 內容寬 | 不截斷；整張表比畫面寬時可橫向捲動 |
| `default`（預設） | 扣掉最大欄與縮到內容寬的最小欄之後，剩下的寬度均分 | 截斷並加「…」 |
| `min`（最小） | 內容寬，但不超過預設欄分到的一份 | 內容比一份寬時與預設欄一同均分，截斷並加「…」 |

- **一份的下限**：各欄的內容寬加總超出可用寬度時，預設欄的一份不少於把最大欄也算作一份時分到的寬度（最大欄本身仍為內容寬），此時表格比畫面寬，可橫向捲動。全部放得下時不設下限
- **沒有預設欄、最小欄皆放得下時**，多出的寬度由最大欄均分，表格撐滿
- **只有最小欄時**，全部的欄均分可用寬度，不再貼齊內容寬
- 同一種設定的欄視為同一層級，預設欄之間均分而不依內容寬；不希望較寬的欄被截斷時，將較窄的欄設為最小
- **設了 `wrap` 時**，上表「截斷並加『…』」之處改為換行，該列隨之變高；欄寬的計算不變，最大欄仍完整顯示於一行
- 以程式量出各欄的內容寬後，以 `colgroup` 固定每欄的寬度（`table-layout: fixed`）；資料或表格的可用寬度改變時重算。計算見 `composables/list/useColumnWidths.ts`

## 固定欄

`fixed` 為 `n` 時，前 `n` 欄於表格橫向捲動時停在左側，其餘的欄自其底下捲過。

- **欄寬不因固定而改變**，照上方的規則計算；固定欄的位置為前面各欄寬度的加總，例如第一欄寬 100px 時，第二欄自 100px 處開始
- 固定欄的背景不透明，最後一個固定欄的右側以較深的格線分隔
- 表頭隨表格一同固定於左側，但不固定於上方
- 表格未超出可用寬度時不會捲動，固定欄與一般的欄看起來相同，僅分隔線較深；`fixed` 超過欄數時全部固定
