# DashboardPage

同時顯示多個面板的整頁版型，與一次只顯示一個面板的 [TabPage](TabPage.md) 相對。每個面板以 [DashboardPanel](DashboardPanel.md) 包住。面板中可直接放入既有的列表頁與詳細頁（以元件 import），或以 `ListPage`、`DetailPage` 等元件組成。

此元件負責整頁層級的事：
- 方格排版
- 關注點
- 各列表面板共用的搜尋與篩選
- App Bar 的動作與標題
- 展開
- 互動的選取
- 多選時鎖定其他面板

## Usage

範本見 `template/pages/dashboard.vue`：父表列表、父表詳細與子表列表三個面板，並開啟互動。

## Props

| prop | 型別 | 說明 |
| --- | --- | --- |
| `layout` | `Record<string, { mobile?: PanelSize, desktop?: PanelSize }>?` | 面板的 `name` → 手機與電腦的排版。`PanelSize` 為 `{ x?, y?, w?, h? }`，皆以格數表示，`x`、`y` 自 1 起算。未列出的面板或留空的斷點為自動 |
| `interactive` | `boolean?` | 預設 `false`。開啟時點擊一列改為選取，與該列直接相關的面板跟著改變（見下方「互動」） |

## Slots

| slot | 說明 |
| --- | --- |
| `default` | 放 `DashboardPanel`。宣告的順序即排版的順序 |

## 排版

- **方格**：手機寬 6 格，電腦寬 24 格。格子為正方形（高等於寬），間距 8px
  - 手機或電腦由 `useCompactLayout()` 決定，目前沿用 Vuetify 的 `mobile`（1145px）
  - 排版相關之處皆只讀取 `useCompactLayout()`，並寫入此元件的 `data-layout` 屬性。CSS 以屬性選擇器切換 6 格或 24 格
- **三種排版**：
  - 固定：`{ w, h }`，寬與高皆為指定的格數
  - 只控制高：`{ h }`，高為指定的格數，寬與自動排版相同（手機填滿，電腦 8 格）
  - 自動：未列出或留空。手機的寬填滿，高依內容，最多 8 格。電腦寬 8 格，高 7 格
- **面板最少 2 格寬**
- **依宣告的順序逐一放入**：
  - 沒有座標的面板接在上一個面板的右側
  - 只提供 `y` 時，面板從該列的開頭開始。只提供 `x` 時，面板與上一個面板同一列
  - 面板重疊時，移動後宣告的那一個：先往右移，放不下再換到下一列的開頭。指定的座標因此被改動時，開發模式下於 console 警告
- **面板在自己的框內捲動**，捲到底時繼續滑動即帶動整頁
- **位置由 `placePanels` 計算**：`placePanels` 為純函數，CSS 只依結果繪製
- **手機上依內容撐高的面板**一列只放它自己。高度改變時，只有其下方的面板整排上下移動，左右的排列不變

## App Bar、FAB 與搜尋

| 狀態 | App Bar | FAB |
| --- | --- | --- |
| 平時 | 搜尋（含篩選、排序） | 不顯示 |
| 關注面板在多選模式 | 該面板的多選動作與「取消」 | 不顯示 |
| 面板已展開 | ← 與面板的標題、該面板的動作 | 該面板的 FAB |

- **面板中的 `useAppBarActions` 無須修改**：此元件 provide `appBarActionsKey`。面板交出的動作先交到此元件，只有關注面板的動作生效。此元件再依上表決定是否顯示，並統一登記一次
- **搜尋字串為全頁共用**：輸入一次，所有列表面板一起過濾
- **篩選與排序每張表各一份**：同一張表出現於多個面板時共用。篩選抽屜開啟時，先停在關注面板的表
- **只要有任一個列表面板，就出現放大鏡**，不受關注點影響
- 一個面板的資料依序經過：整張表 → 互動（依所選的父列篩出子列，與 `useListPage` 的 `scope` 同一步）→ 篩選 → 搜尋

## 展開

- **小外殼右側的展開按鈕**將該面板就地放大為整頁，其他面板暫時隱藏。展開的面板與一般頁面相同：FAB、App Bar 的動作、多選、詳細頁的上一列與下一列、左右滑動皆恢復
- **展開時以同一個網址推入一筆 history**，並在該筆 history 的 state 記下展開的面板：
  - 按返回鍵或 App Bar 的 ← 即縮回
  - 瀏覽器的下一頁、從展開的面板進入其他頁面再返回、重新整理之後，皆維持展開
- **展開與否一律依目前這一筆 history 的 state 決定**：此元件在每次導覽完成後（`router.afterEach`）與掛載時讀取 state。展開按鈕只推入 history，不直接改變狀態
- **網址不變，KeepAlive 不重建此頁**：面板中的狀態皆保留，例如分組的收合、多選、搜尋字串。router 的 `scrollBehavior` 在推入相同網址時回到頂端，返回時依瀏覽器記下的位置還原
- **App Bar 的標題為面板的 `title`**，此元件以 `useAppBarHeading()` 登記標題與縮回
- **互動的狀態保留**：例如子表面板展開後，仍只列出所選父列的子列
- 動畫與換頁相同，展開如同前進到新頁面

## 互動

開啟 `interactive` 時，每張表各記一列選取。與選取的那一列直接相關的面板，依下表跟著改變：

| 面板 | 連動方式 |
| --- | --- |
| 同一張表的詳細面板 | 顯示選取的那一列 |
| 同一張表的列表面板 | 選取的那一列左側加一條主色的細邊 |
| 子表的列表面板 | 只列出選取的那一列的子列 |
| 父表的詳細面板 | 顯示選取的那一列所屬的父列 |

- **點擊一列只選取，不換頁**。手機上即使相關的面板不在畫面內，也只選取
- **取消選取**：
  - 再點一次選取的那一列，即取消
  - 父列的選取改變時，清除子表的選取
  - 選取的那一列被刪除時，自動取消該表的選取，並連帶清除子表的選取
- **選取的那一列被搜尋或篩選隱藏時，選取保留**：子表照樣只列出它的子列，子列也經過搜尋與篩選
- **尚未選取父列時，子表面板列出全部的子列**。子表指向兩張父表、且兩張皆有選取時，只列出同時屬於兩者的子列
- **詳細面板尚未選取時只顯示欄位名稱**，不顯示「找不到這筆資料」。依賴該列的區塊（例如子表區塊）與標頭不顯示
- **展開的詳細面板中**，上一列、下一列與左右滑動改為切換選取，不離開 dashboard。順序由最後一個關注的列表面板發布，列表面板只在關注時發布順序
- **選取改變時，面板以轉場切換**：
  - 點擊時各面板淡入淡出，內容沒有改變的面板看不出動畫
  - 手機上依內容撐高的面板，高度的變化也平滑過渡
  - 展開的詳細面板切換上一列、下一列時左右滑動，App Bar 與上一列、下一列的箭頭不動
  - 瀏覽器不支援 View Transitions，或開啟「減少動態效果」時，直接切換
- **只連動一層**：
  - 子表的子表不連動，指向自己的 ref 欄位也不連動
  - 表格（`DataTable`）的列不支援選取，點擊照常換頁
  - 多個 ref 欄位指向同一張表時，以 `DashboardPanel` 的 `via` 指定
- **選取狀態只存於此元件中，不寫入網址**：
  - 與其他頁面相同，選取狀態由 KeepAlive 保留。從面板進入其他頁面再返回，選取仍在
  - 重新整理，或此頁被擠出快取（上限 50 個頁面）時，選取清除
  - 「離開即取消選取」只適用於多選，與互動的選取無關

## 備註

- **不可與 `TabPage` 互相嵌套，也不可嵌套自身**，開發模式下於 console 警告。含頁籤的列表頁拆出 `_ref/` 中的單純列表後再放入（見 [search.md](../../topics/search.md#同一頁面中的多張表)）
- **同一時間只有一個面板能多選**：多選期間其他面板調暗，點擊與長按皆無作用，捲動仍可使用
- **面板內容依面板的寬度切換窄版**：3 格以下時，deck、card、詳細頁的欄位與動作列改用精簡的版面（見 [DashboardPanel](DashboardPanel.md)）
