# DashboardPage

同時顯示多個面板的整頁版型，與一次只顯示一個面板的 [TabPage](TabPage.md) 相對。每個面板以 [DashboardPanel](DashboardPanel.md) 包住。面板中可直接放入既有的列表頁與詳細頁（以元件 import），或以 `ListPage`、`DetailPage` 等元件組成。

此元件負責整頁層級的事：
- 方格排版
- 關注點
- 搜尋、篩選與排序：加入共用的面板使用全頁的一份，其他面板各有自己的一份
- App Bar 的動作與標題
- 展開
- 面板之間的連動
- 多選時鎖定其他面板

## Usage

範本見 `template/pages/dashboard.vue`：父表列表、父表詳細與子表列表三個面板，並以連動中心接線。

## Props

| prop | 型別 | 說明 |
| --- | --- | --- |
| `layout` | `Record<string, { mobile?: PanelSize, desktop?: PanelSize }>?` | 面板的 `name` → 手機與電腦的排版。`PanelSize` 為 `{ x?, y?, w?, h? }`，皆以格數表示，`x`、`y` 自 1 起算。未列出的面板或留空的斷點為自動 |
| `links` | `DashboardLinks?` | `useDashboardLinks()` 建立的連動中心（見下方「連動」）。面板之間不須連動時省略 |

## Slots

| slot | 說明 |
| --- | --- |
| `default` | 放 `DashboardPanel`。宣告的順序即排版的順序 |

## 排版

方格、面板的大小與位置的規則，見設計文件的[尺寸](../../design/dashboard.md#尺寸)與[排版](../../design/dashboard.md#排版)。此元件的實作如下：

- **手機或電腦由 `useCompactLayout()` 決定**：排版相關之處皆只讀取 `useCompactLayout()`，並寫入此元件的 `data-layout` 屬性。CSS 以屬性選擇器切換兩種方格
- **三種排版對應 `PanelSize` 的寫法**：固定為 `{ w, h }`，只指定高為 `{ h }`，自動為未列出或留空
- **位置由 `placePanels` 計算**：`placePanels` 為純函數，CSS 只依結果繪製
- **指定的座標因面板重疊而被改動時**，開發模式下於 console 警告

## App Bar、FAB 與搜尋

| 狀態 | App Bar | FAB |
| --- | --- | --- |
| 平時 | 關注面板的搜尋（含篩選、排序）：加入共用的面板為全頁的一份，其他面板為該面板的一份 | 不顯示 |
| 關注面板在多選模式 | 該面板的多選動作與「取消」 | 不顯示 |
| 面板已展開 | ← 與面板的標題、該面板的動作 | 該面板的 FAB |

- **面板中的 `useAppBarActions` 無須修改**：此元件以 `relaySlot` 收下面板交出的動作，只有關注面板的動作生效。此元件再依上表決定是否顯示，並登記一次
- **多選的出口與面板自己的搜尋也經過此元件**：`DashboardPanel` 以 `relaySlot` 收下內容登記的值，此元件只登記關注面板的那一份
- **每個面板以 `shared` 決定是否加入全頁共用的搜尋、篩選與排序**（見 [DashboardPanel](DashboardPanel.md)），預設不加入：
  - 加入時，搜尋字串為全頁共用，輸入一次，所有加入共用的面板一起過濾。篩選與排序每張表各一份，同一張表出現於多個加入共用的面板時共用
  - 不加入時，面板有自己的搜尋、篩選與排序，與一般頁面相同
- **App Bar 操作關注面板的一份**：關注不加入共用的面板時，為該面板的一份。關注加入共用的面板，或沒有列表的面板時，為全頁共用的一份
- **全頁共用的一份中有任一個列表時，才出現放大鏡**。關注沒有列表的面板，且沒有面板加入共用時，不出現放大鏡
- **放大鏡的顏色**依 App Bar 目前操作的那一份是否有條件
- 篩選抽屜開啟時，先停在關注面板的表
- 一個面板的資料依序經過：整張表 → 面板的 `scope`（與 `useListPage` 的 `scope` 同一步）→ 篩選 → 搜尋

## 展開

- **小外殼右側的展開按鈕**將該面板就地放大為整頁，其他面板暫時隱藏。展開的面板與一般頁面相同：FAB、App Bar 的動作、多選、詳細頁的上一列與下一列、左右滑動皆恢復
- **展開時以同一個網址推入一筆 history**，並在該筆 history 的 state 記下展開的面板：
  - 按返回鍵或 App Bar 的 ← 即縮回
  - 瀏覽器的下一頁、從展開的面板進入其他頁面再返回、重新整理之後，皆維持展開
- **展開與否一律依目前這一筆 history 的 state 決定**：此元件在每次導覽完成後（`router.afterEach`）與掛載時讀取 state。展開按鈕只推入 history，不直接改變狀態
- **網址不變，KeepAlive 不重建此頁**：面板中的狀態皆保留，例如分組的收合、多選、搜尋字串。router 的 `scrollBehavior` 在推入相同網址時回到頂端，返回時依瀏覽器記下的位置還原
- **App Bar 的標題為面板的 `title`**，此元件以 `useAppBarHeading()` 登記標題與縮回
- **連動的狀態保留**：例如子表面板展開後，仍只列出所選父列的子列
- 動畫與換頁相同，展開如同前進到新頁面

## 連動

頁面以 `useDashboardLinks()` 建立一份連動中心，以 `links` prop 交給自己的 `DashboardPage`。頁面再以連動中心的小工具，把一個面板的輸出接到其他面板的輸入。

- **每次呼叫建立一份新的連動中心**：每個儀表板頁面各有一份，互不影響。面板的 `name` 只在自己的一份中有效
- **未傳入 `links` 時**，此元件自己建立一份。面板照常輸出，但沒有面板接收
- **接線只在頁面中**：列表元件與詳細頁不知道接線，同一個頁面單獨開啟時不受影響

### 面板的輸出

每個面板自動輸出兩項，頁面無須設定：

| 輸出 | 內容 | 寫入者 |
| --- | --- | --- |
| `selected` | 選取的那一列 | 開啟 `selects` 的面板中的 `ListPage` |
| `shown` | 列出的列，依顯示的順序。詳細頁為顯示的那一列，只顯示欄位名稱時為零列 | `ListPage`、`ChartPage` 與 `DetailPage` |

- 頁籤中的列表、圖表與詳細頁只在目前的頁籤時輸出。載入中不輸出
- 不使用 `ListPage`、`ChartPage` 或 `DetailPage` 的內容沒有輸出

### 面板的輸入

輸入為 `DashboardPanel` 的 prop（見 [DashboardPanel](DashboardPanel.md)），值皆為小工具的回傳值：
- `scope`：面板中的內容依種類使用。列表只保留其中的列，詳細頁在剛好一列時顯示這一列
- `mark`：列表以另一種顏色標示其中的列，不影響列出哪些列

### 小工具

小工具為連動中心的方法，以 `links.childrenOf(...)` 的形式呼叫。每個小工具皆回傳一張表中的一組列（`Link`），可以交給面板，也可以作為其他小工具的來源。

| 類別 | 小工具 | 說明 |
| --- | --- | --- |
| 面板 | `selectionOf(panel, notSelected)` | 面板中選取的那一列。沒有選取時，`notSelected` 為 `'all'` 即沒有條件，為 `'none'`（預設）即沒有列 |
| 面板 | `shownOf(panel)` | 面板中列出的列，依顯示的順序。面板尚未列出時沒有列 |
| 過濾 | `parentOf(source, column)` | 來源的列以 `column` 指向的父列。`column` 為來源那張表的 ref 欄位，可以是虛擬的 ref 欄位 |
| 過濾 | `childrenOf(source, column, { within })` | `within` 中以 `column` 指向來源的列。`column` 為 `within` 那張表的 ref 欄位 |
| 合併 | `and(a, b, ...)` | 每一個都有的列 |
| 合併 | `or(a, b, ...)` | 任一個有的列 |
| 合併 | `pickLatest(a, b, ...)` | 有列的來源中最後改變的一個。都沒有列時為全部中最後改變的一個 |
| 合併 | `pickFirst(a, b, ...)` | 依順序第一個有列的來源。都沒有列時為最後一個 |
| 合併 | `not(a)` | 同一張表中不在 `a` 的列 |

- **來源可以是表名**，表示整張表。表尚未載入時沒有列。面板的值須以 `selectionOf` 或 `shownOf` 取得
- **「沒有條件」與「沒有列」不同**。沒有條件表示不限制，交給面板時列出全部的列。沒有列為零列，交給面板時不列出任何列
- **各小工具收到沒有條件的來源時**：

  | 小工具 | 結果 |
  | --- | --- |
  | `parentOf`、未指定 `within` 的 `childrenOf` | 沒有條件 |
  | 指定 `within` 的 `childrenOf` | `within` 本身 |
  | `and` | 略過這個來源。全部沒有條件時沒有條件 |
  | `or` | 沒有條件 |
  | `pickLatest`、`pickFirst` | 與沒有列的來源同樣排在有列的來源之後 |
  | `not` | 沒有列 |

- **`childrenOf` 的來源有條件時，排除 ref 為空的列**，結果依 `within` 的順序
- **`within` 可以是表名或其他小工具的回傳值**。未指定時為收到的面板的整張表：
  - 結果須交給面板，或交給合併的小工具後再交給面板。面板以自己的 `table` 算出列，因此面板須指定 `table`
  - 不能作為 `parentOf` 或 `childrenOf` 的來源，開發模式下於 console 警告
- **面板收到的 `scope`**，依內容的種類使用：
  - 列表：未傳入或沒有條件時不限制。沒有列時不列出任何列
  - 詳細頁：剛好一列時顯示這一列。未傳入、沒有條件、沒有列或多於一列時，只顯示欄位名稱
- **面板收到的 `mark` 未傳入或沒有條件時**，列表不標示任何列
- **以下情況於開發模式下在 console 警告**：
  - `column` 不是 ref 欄位，或 `childrenOf` 的 `column` 不指向來源的表
  - 合併的各值不是同一張表
  - 面板收到的值不是面板的表
  - 來源的字串不是表名
  - `selectionOf` 或 `shownOf` 的面板名稱不存在
  - 以 `shownOf` 接線形成循環：一個面板列出的列在同一輪中改變 10 次即警告。`selectionOf` 可以雙向接線，選取只由點擊改變

### 選取

- **點擊一列即選取，再點一次即取消**。手機上即使相關的面板不在畫面內，也只選取
- **選取的列不再列出時，自動取消**：例如被搜尋或篩選隱藏、被刪除，或父列的選取改變。之後再列出時，不恢復選取
- **選取的那一列左側加一條細邊**
- **面板的 `mark` 中的列，左側加一條較淡的細邊**：
  - 例如父表的詳細面板顯示所選子列的父列時，父表列表的 `mark` 以 `shownOf` 取得詳細面板的那一列
  - 同時為選取的那一列時，顯示選取的細邊
  - 點擊即成為選取
- **表格（`DataTable`）的列不支援選取**，點擊照常換頁
- **選取改變時，面板以轉場切換**：
  - 點擊時各面板淡入淡出，內容沒有改變的面板看不出動畫
  - 手機上依內容撐高的面板，高度的變化也平滑過渡
  - 展開的詳細面板切換上一列、下一列時左右滑動，App Bar 與上一列、下一列的箭頭不動
  - 瀏覽器不支援 View Transitions，或開啟「減少動態效果」時，直接切換
- **選取狀態只存於連動中心，不寫入網址**：
  - 與其他頁面相同，選取狀態由 KeepAlive 保留。從面板進入其他頁面再返回，選取仍在
  - 重新整理，或此頁被擠出快取（上限 50 個頁面）時，選取清除
  - 「離開即取消選取」只適用於多選，與面板的選取無關

### 詳細面板

- **沒有輸入時只顯示欄位名稱**，不顯示「找不到這一列」。依賴該列的區塊（例如子表區塊）與標頭不顯示
- **展開時的上一列、下一列與左右滑動**：
  - `scope` 為列表面板的選取（`selectionOf`，或 `pickLatest`、`pickFirst` 選出的選取）時，移動該列表的選取，不離開 dashboard。順序為該列表目前列出的列
  - `scope` 為其他的值時停用，例如 `parentOf`、`shownOf` 或 `and` 的結果

## 備註

- **不可嵌套自身**，開發模式下於 console 警告
- **可與 `TabPage` 互相嵌套**：此元件可置於 `TabPage` 的頁籤中，`TabPage` 也可置於面板中（見 [TabPage](TabPage.md)）
- **同一時間只有一個面板能多選**：多選期間其他面板調暗，點擊與長按皆無作用，捲動仍可使用
- **面板內容依面板的寬度切換窄版**：[窄面板](../../design/dashboard.md#窄面板)中，deck、card、詳細頁的欄位與動作列改用精簡的版面（見 [DashboardPanel](DashboardPanel.md)）
