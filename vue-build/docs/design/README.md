# UI/UX 設計指南

這組文件從使用者看到的畫面介紹各種頁面：外觀、用途、操作方式，以及規劃一個頁面時須決定的事。這組文件不涉及程式的寫法，實作方式見各份文件末尾列出的技術文件。

外觀以手機優先，電腦上沿用同一套版面。

---

## 各種頁面

| 頁面 | 用途 | 文件 |
| --- | --- | --- |
| 列表頁 | 瀏覽一張表的資料，找到某一列，一次處理多列 | [list.md](list.md) |
| 詳細頁 | 查看一列的完整內容，以及它的子列 | [detail.md](detail.md) |
| 表單頁 | 新增或編輯一列 | [form.md](form.md) |

## 畫面的各部位

所有頁面共用同一個外殼。手機版由上而下為 App Bar、內容區與底部導覽列。電腦版沒有底部導覽列，左側為固定的側邊欄。另有幾個浮在內容上的元素。

| 部位 | 位置 | 用途 |
| --- | --- | --- |
| **App Bar** | 頂部，固定不動 | 顯示頁面的標題，以及這一頁的動作 |
| **左側圖示** | App Bar 最左側 | 有上一頁可回時為返回鍵。手機版沒有上一頁時為選單鍵，按下選單鍵開啟側邊欄。電腦版沒有上一頁時不顯示 |
| **App Bar 的動作** | App Bar 右側 | 這一頁的次要動作，例如刪除。兩個以內直接顯示為圖示，三個以上收進「⋮」選單 |
| **搜尋按鈕** | App Bar 右側 | 只有列表頁有。按下後，整條 App Bar 換成搜尋列 |
| **排序按鈕** | 搜尋按鈕右側 | 列表頁的表有可排序的欄位時才有。不是預設的排序時，以主色標示 |
| **同步按鈕** | App Bar 最右側 | 與試算表同步資料，所有頁面皆有 |
| **頁籤列** | App Bar 下方 | 只有頁籤頁有，捲動內容時固定不動。換頁時隨內容滑動 |
| **內容區** | 中間 | 頁面的主體，換頁時左右滑動 |
| **側邊欄** | 左側 | 上方為 App 名稱，中間為可展開的頁面分組，最下方為「登出」。手機版預設收起，按選單鍵開啟。電腦版固定顯示，可收合為圖示列 |
| **篩選與排序的抽屜** | 從右側滑出 | 設定列表的篩選條件或排序方式，一次顯示其中一種 |
| **FAB** | 右下角，浮在內容上 | 這一頁最主要的動作，例如新增、編輯 |
| **底部導覽列** | 底部 | 只有手機版有。切換主要的幾個頁面，最多 5 項 |
| **底部動作列** | 底部 | 表單頁的「取消」與「送出」，表單蓋住底部導覽列 |
| **訊息** | 底部，短暫顯示 | 告知動作的結果，例如「已推送」或失敗的原因 |
| **上一列、下一列的箭頭** | 詳細頁的左右兩側 | 切換到列表中的上一列或下一列 |
| **對話框** | 畫面中央 | 確認是否執行，或詢問幾個欄位的值 |

- **App Bar 高 58px**：手機與電腦相同，表單頁的 App Bar 也相同

## 導覽

- **最主要的頁面放在底部導覽列，最多 5 項**，一般為最常用的列表頁與儀表板。依 Material Design 的建議，超過 5 項時不顯示
- **底部導覽列的按鈕平分整列的寬度**：每個按鈕最寬 168px，畫面窄時按鈕縮小，不超出畫面。名稱放不下時以「…」截斷
- **底部導覽列高 78px**：圖示 28px，圖示與名稱相距 6px
- **目前的頁面以主色標示**：底部導覽列的按鈕與側邊欄的項目皆同。圖示與名稱為主色，底色疊上一層淡淡的主色
- **其他按鈕的圖示與名稱為次要文字的顏色**：與 `text-medium-emphasis` 相同，比內文淡
- **其他頁面放在側邊欄**：側邊欄的清單與底部導覽列各自設定，同一頁可以兩處皆有
- **側邊欄中組內的頁面縮排一層**：圖示比組標題的圖示右移 16px
  - 頁面可以分組。有標題的組可以展開與收合，標題前可加圖示。目前的頁面所在的組自動展開
- **側邊欄的頁面超出高度時，只有頁面清單捲動**：最上一列與「登出」固定
- **手機版的側邊欄開啟後浮在內容上**：點擊側邊欄以外的地方，或換頁後收起
- **電腦版沒有底部導覽列，側邊欄固定於左側**：
  - 最上方為底部導覽列的頁面，接著為側邊欄的組。側邊欄中與底部導覽列重複的頁面不再列出
  - 組之間以分隔線分開，分隔線上下各留 4px
  - 展開時寬 256px，收合為圖示列時寬 56px（皆為 Vuetify 的預設）
  - 收合為圖示列時，每個頁面為 48px 見方，與左右兩緣的距離各為 4px，圖示置中。選取時的底色因此為正方形
  - 收合為圖示列時不顯示捲軸，頁面超出高度時仍可捲動
  - 頁面的圖示與收合鍵於展開與收合時位置不變
  - 最上一列與 App Bar 同高。收合鍵位於左端，與左緣的距離為 4px。展開時收合鍵右側為 App 名稱，間距 8px。收合時只有收合鍵，與 App Bar 的返回鍵並排
  - 收合為圖示列時，組不展開，所有頁面直接以圖示列出。滑鼠停在圖示上時顯示頁面的名稱
  - 預設收合。收合與否只在執行期間記住，重新整理後回到收合
- **底部導覽列與側邊欄的頁面皆為頂層頁面**：兩者之間的切換不留下上一頁，返回鍵不在這些頁面之間來回。手機版的 App Bar 左側為選單鍵，電腦版不顯示左側圖示
- **從列表進入詳細頁，再進入表單頁**：每一層皆可按返回鍵，或 App Bar 左側的返回鍵，回到上一層
- **換頁時內容區左右滑動**：
  - 前往新的頁面時，新內容從右側滑入。返回時從左側滑入
  - 頂層頁面之間依位置決定方向：底部導覽列由左而右，側邊欄的頁面接在其後
  - App Bar、底部導覽列與 FAB 不隨內容滑動
- **回到看過的頁面時，停在原本捲動的位置**。第一次開啟的頁面從頂端開始
- **登入頁等特殊頁面可以不顯示外殼**，整頁由頁面自行安排

## 多選

- **長按列表的一列，進入多選**。各種版面的操作見 [list.md](list.md)
- **多選時，App Bar 右上角出現「取消」**：
  - 「取消」固定在同步按鈕的左側，不收進「⋮」選單
  - 搜尋與排序暫時隱藏
  - App Bar 的動作換成對選取的列的動作
- **多選在以下情況自動結束**：取消所有勾選、按「取消」、換頁、換頁籤

## 動作的位置

| 位置 | 用途 |
| --- | --- |
| 右下角的 FAB | 這一頁最主要的動作，例如列表頁的新增、詳細頁的編輯。手機版兩個以內各自一個按鈕。三個以上時收成一個按鈕，按下後展開，每個動作旁顯示名稱。電腦版不收合，各自一個按鈕，每個動作旁一律顯示名稱 |
| App Bar 右側 | 次要的動作，例如刪除。多選時為對選取的列的動作 |
| 螢幕最底端 | 表單頁的取消與送出 |
| 列表的每一列 | 該列的動作，例如編輯、刪除。各種版面放置的位置不同，見 [list.md](list.md) |
| 詳細頁的單一欄位 | 與該欄位相關的動作，例如前往關聯的另一列、開啟網址 |
| 詳細頁的標頭 | 這一列的動作，置於標頭下方 |
| 詳細頁中子表區塊的右下角 | 例如新增一列子列 |

- **不適用的動作不顯示**。例如沒有選取任何一列時，不顯示刪除選取的列
- **需要確認的動作先顯示確認框**，例如刪除。確認後才執行
- **動作失敗時，以訊息告知原因**
- **動作可以顯示為圖示或文字**：一般為圖示，須特別強調的動作可改為主色的文字

## 確認與詢問

- **確認框**：畫面中央的對話框，說明即將發生的事，並提供「確定」與「取消」。有兩種以上的做法時，可提供多個選項
- **詢問幾個欄位**：只須修改一兩個欄位時，不開啟整頁表單，改以對話框只詢問那幾欄（見 [form.md](form.md)）
- **離開未儲存的表單時**，詢問是否放棄變更（見 [form.md](form.md)）

## 尺寸與樣式

- **一律預留整頁捲軸的寬度**：電腦上內容不須捲動時，右側仍留出捲軸的寬度。捲軸出現或消失時，內容的寬度不變。手機的捲軸疊於內容之上，不佔寬度
- **生效中的按鈕以主色顯示**：有搜尋字串或篩選條件時的放大鏡、有條件生效時的篩選按鈕，以及不是預設排序時的排序按鈕
- **共用的七種顏色**（紅、橙、黃、綠、藍、紫、灰），用於條件式格式與文字統計的數字：
  - 色值取自 Material Design 色板。淺色主題使用較深的色值，深色主題使用較淺的色值
  - 兩者皆以 APCA 對 Vuetify 預設的底色（淺色 `#FFFFFF`、深色 `#212121`）檢查，達 Lc 60 以上
  - 黃色例外：深色主題為 yellow A700（`#ffd600`）。淺色主題為同一色相（OKLCH）降低亮度至達標的 `#a58a08`，不在色板上
- **條件式格式的圖示**約與文字同高
- **FAB**：
  - 與螢幕右緣的距離為 24px，與底部導覽列（電腦版為螢幕下緣）的距離為 24px
  - FAB 為 56px 見方（Vuetify 的 large）。收合的 FAB 展開後的各個動作為 48px（Vuetify 的 default）
  - 圓角為 16px。收合的 FAB 展開後的各個動作也相同
  - 電腦版的動作各自為 56px 的 FAB，由下往上排列，間距 12px
  - 底色為主色淡一階（Vuetify 的 `primary-lighten-1`）
  - 收合的 FAB 展開時，各個動作由下往上依序滑入。收合時整排動作向下滑出
