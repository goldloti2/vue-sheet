# 表單頁

新增或編輯一列資料。新增頁與編輯頁的外觀相同，差別在於編輯頁一開始就填好這一列目前的值。

表單蓋住整個畫面。最上方為返回與標題，最底端為「取消」與「送出」。

---

## 欄位與輸入方式

欄位的先後預設由這張表統一決定，個別頁面可以另外指定。例如新增頁多一個編號欄，編輯頁沒有。每種欄位有對應的輸入方式：

| 欄位 | 輸入方式 |
| --- | --- |
| 文字 | 一般的文字框 |
| 長文 | 多行的文字框，按 Enter 換行，高度隨內容增加 |
| 數字 | 數字框，右側有減與加的按鈕。每次的增減可以設定（例如 0.5）。可限制最小值與最大值 |
| 日期 | 日期選擇器 |
| 是非 | 名稱在左，「否」「是」兩個相連的按鈕在右側置中。再按一次已選取的按鈕即清空，可以不填 |
| 時長 | 文字框，以「時:分:秒」填寫，時數不限 |
| 選項 | 下拉選單，只能選擇定義好的選項。也可以設定為允許自行輸入，此時選項只是建議，並可附上資料中用過的值 |
| 關聯 | 可搜尋的下拉選單，列出父表各列的名稱 |
| 圖片 | 文字框，貼上圖片網址或雲端硬碟的連結 |
| 算出來的值 | 例如總額。以較淡的字顯示，不能修改，隨其他欄位的輸入即時更新 |

**編號**：每一列有一個不重複的編號。
- 編號可以由系統自動產生
- 編號也可以放進新增表單，由使用者填寫（例如商品編號），或選擇所屬的父列而與父列共用編號。留空時仍自動產生
- 編號只能使用英文字母、數字與少數符號（例如 `-`、`_`），不能以數字開頭
- 編號建立後不能修改。編輯頁中以較淡的字與鎖頭圖示顯示，可以選取複製

---

## 預設值

新增頁的欄位可以預先填好：

- **固定的預設值**，例如日期預設為今天
- **依按下新增的位置而定**。例如從「已完成」頁籤新增時，狀態預設為已完成。從訂單的詳細頁新增明細時，明細預設屬於這張訂單

編輯頁一律以這一列目前的值開始。

---

## 檢查與錯誤

- **可以檢查的事**：必填、數字的範圍、只能選擇定義好的選項，以及這張表自訂的規則（例如結束日期不能早於開始日期）
- **必填的欄位在名稱後面有紅色的「*」**。唯讀的欄位不標示
- **第一次按下送出之前，不顯示錯誤**。按過一次之後，修改時即時更新
- **錯誤顯示在該欄位的下方**。送出本身失敗時，錯誤顯示在整個表單的下方，表單內容保留

---

## 送出與離開

- **送出成功後，回到上一頁**。例如從詳細頁進入編輯，儲存後回到詳細頁。沒有上一頁時，前往這張表的列表，或那一列的詳細頁
- **按「取消」、返回鍵或切換頁面時**，若表單修改過，先詢問是否放棄變更
- **表單開啟時，暫停與試算表同步**

---

## 連續的幾個步驟

有些操作須依序填寫幾張表單。例如新增一張訂單之後，接著新增它的第一列明細，最後進入那張訂單的詳細頁：

- **每一步都是一張完整的表單**，送出後直接進入下一步
- **中途離開即整個取消**：前面已送出的步驟一併還原，不留下做到一半的資料
- **第二步起，離開時一律詢問**，並說明會連同之前的變更一起放棄

---

## 快速修改

只想修改一兩個欄位時，無須開啟整頁表單：

- **以對話框只詢問那幾個欄位**，例如修改狀態、補上日期。輸入方式與檢查和整頁表單相同
- **多選後一次修改多列**：所有選取的列改成同一個值。此時不顯示目前的值
- **只修改一列時，以目前的值開始**
- 只須回答是或否時，使用確認框

---

## 設計時須決定的事

- **欄位**：表單中有哪些、先後順序，新增與編輯是否不同
- **編號**：自動產生，或由使用者填寫、與所屬的父列共用
- **必填與檢查**：哪些欄位必填、數字的範圍、自訂的規則
- **預設值**：固定的預設值，以及從各處新增時預先帶入的值
- **選項**：是否允許自行輸入、是否附上資料中用過的值
- **連續的步驟**：哪些操作須一次填寫幾張表單
- **快速修改**：哪些欄位常須單獨修改，或須對多列一次修改
