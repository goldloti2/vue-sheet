# 列表頁

一張表的資料逐列排開，用來瀏覽、找到某一列，以及一次處理多列。點擊一列，即進入該列的詳細頁。

App Bar 中有搜尋與排序，以及這一頁的動作。右下角的 FAB 通常為新增。

---

## 五種版面

每一列的呈現方式有五種。同一張表可以換用不同的版面，各位置放置的欄位另行指定。

| 版面 | 外觀 | 每一列的動作 | 適合 |
| --- | --- | --- | --- |
| deck | 連成一串的列，左側一張小縮圖，四個角各一個欄位 | 列的下方一排按鈕，靠右 | 一般的瀏覽，一列可看到較多欄位 |
| profile | 分開的卡片，左側圓形頭像，中間標題與副標 | 右側的 ⋮ 選單 | 以人或物為主體、資訊精簡的表 |
| card | 分開的卡片，上下四層：頭像與標題、大圖、標題與摘要、動作 | 第四層，左右各兩格 | 圖片與說明並重的表 |
| gallery | 方格排列，上方正方形圖片，下方標題與副標。手機上為兩欄 | 右下角的 ⋮ 選單 | 以圖片為主的表 |
| table | 表格，一列一筆資料，一欄一個欄位 | 無 | 同時比對多個欄位 |

各版面的文字皆可依這一列的內容改變呈現，即條件式格式：改變顏色、粗體、斜體、底線、刪除線，或在值前面加上圖示。例如逾期的日期顯示為紅色，並加上警告圖示。

### deck

- 左側的縮圖可省略。已指定但這一列沒有圖片時，保留一塊同大小的空白
- 四個角：左上為標題（粗體），右上為副標，左下為摘要，右下為補充
- 每個角皆可不放欄位。放了欄位但這一列沒有值時，保留該位置，各列因此對齊
- 左右兩側的寬度為 7:3，不隨內容改變。同一側的兩個角皆不放欄位時，另一側延伸至整行：左側的文字靠左，右側的文字靠右
- 標題與各欄位最多顯示兩行，過長時以刪節號截斷。右側換成兩行時，標題仍靠上
- 右側的欄位只在標點與空格處換行。一段文字放不下一行時，才於任意處換行

### profile

- 左側的圓形頭像可省略，省略時標題往左靠齊。已指定但這一列沒有圖片時，保留一塊同大小的空白
- 只有標題與副標兩行，過長時以省略號截斷
- 動作一律收在 ⋮ 選單中，只有一個動作時也收入選單

### card

由上而下四層。沒有放任何欄位的層整層不出現。放了欄位但這一列沒有值時，保留該位置，大圖以灰色方塊佔位：

1. 圓形頭像，右側為標題與副標
2. 寬度撐滿卡片的大圖，比例固定為 16:9
3. 標題、副標與摘要，摘要最多三行
4. 動作，最多四格，前兩格靠左，後兩格靠右，可以留空格

第一層與第三層可以放相同或不同的欄位，例如第一層放建立者，第三層放名稱與金額。

### gallery

- 圖片為正方形，周圍留白。沒有圖片時，以灰色方塊佔位
- 標題一行，佔滿寬度。副標一行，右側留給 ⋮ 選單
- 依由左往右、再由上往下的順序排列

### table

- 只用於比對欄位，沒有多選，也沒有每一列的動作
- 點擊一列，進入詳細頁

## 版面的選擇

- **沒有圖片的表**：deck。資訊較少、以名稱為主時，可用 profile
- **以人或物為主體，須一眼認出是誰**：profile
- **圖片與文字說明同樣重要**：card
- **圖片是主角，文字只是標註**：gallery
- **須一次比對大量欄位**：table，但無法多選
- 同一張表在不同頁面可以使用不同的版面。例如列表頁用 deck，儀表板的小面板中用 profile

---

## 分組

列表可以依欄位分成幾組，例如依年份，再依月份。

- **每一組有一條標題列**，標題後面以小標籤顯示這一組的列數
- **可以分成多層**，每一層都可以收合。同一層一次只展開一組
- **某一層只有一組時**，該組固定展開，不能收合。例如篩選後只剩「2026年」
- **部分的列可以不再往下分**：例如「待處理」這一組不再細分，展開後直接列出各列
- **使用者選了排序時不分組**，整份列表依所選的方式排列

---

## 點擊與多選

- **點擊一列，進入詳細頁**。按住修飾鍵或以中鍵點擊時，以新分頁開啟
- **長按一列，進入多選**：每一列出現勾選的圓圈，選取的列加上主色的淡底。點擊改為勾選或取消勾選
- **多選時，App Bar 換成對選取的列的動作**，例如刪除選取的列，並在右上角出現「取消」。搜尋與排序暫時隱藏，每一列的動作也隱藏
- **多選在以下情況自動結束**：取消所有勾選、按「取消」、換頁、換頁籤
- table 不支援多選

---

## 搜尋

- **按放大鏡後，整條 App Bar 換成搜尋列**，標題與動作暫時隱藏。按搜尋列左側的返回鍵，即關閉搜尋列
- **有搜尋字串或篩選條件時，放大鏡為主色**。搜尋列收起時，使用者仍看得出列表正被過濾
- **輸入時即時過濾**。比對的對象為文字欄位，以及關聯的父列的名稱
- **以空白分隔多個詞時，每個詞都須符合**。以引號包住的幾個字視為一個詞
- 不分大小寫
- **換頁時搜尋列自動收起**。回到這一頁時，恢復原本輸入的字，並重新開啟搜尋列

---

## 篩選

- **篩選按鈕在搜尋列的最右側**。有條件生效時，以主色標示。按下後，從右側滑出抽屜
- **表沒有可以篩選的欄位時，不出現篩選按鈕**
- **抽屜分兩層**：
  - 第一層列出可以篩選的欄位。已設定條件的欄位，名稱下方以小字顯示目前的條件，右側有一個主色的圓點
  - 點擊一個欄位，進入第二層填寫條件。選項類與是非的欄位為一列一個勾選框。數字、日期與時長為一個範圍，只填一邊也可以
- **選項類與是非的欄位另有「(空白)」**，勾選後才保留沒有值的列
- **選項只列出資料中實際出現過的值**
- **不同欄位的條件須同時成立**。同一欄勾選多個值時，符合其中之一即可
- **修改後即時生效**，無須按套用
- 第一層的「清除」清掉這張表的所有條件。關閉搜尋時，條件也一併清除
- 抽屜開啟時，畫面的其他部分都無法操作，須先關閉抽屜
- 同一頁有多張表時（頁籤頁或儀表板），抽屜上方多一排表的標籤，用來切換要設定的表

---

## 排序

- **排序按鈕在放大鏡右側**。按下後，從右側滑出與篩選相同的抽屜
- **表沒有可以排序的欄位時，不出現排序按鈕**
- **一次只依一個欄位排序**：點擊一個欄位，即依該欄位排序。再點擊一次，切換遞增或遞減。右側的箭頭顯示目前的方向
- **「清除」回到這張表預設的順序**。不是預設的順序時，排序按鈕以主色標示
- 修改後即時生效。重新整理頁面後，回到預設的順序
- 各型別的排序方式：
  - 文字中的數字依大小排序，例如「2」在「10」之前
  - 選項類的欄位依選項定義的先後排序，不在選項中的值排在其後
  - 是非的欄位「否」在前、「是」在後
  - 關聯的欄位依父列的名稱排序
  - 沒有值的列一律排在最後

## 尺寸與樣式

**各版面共用**：
- **deck 的列與分組的標題貼齊列表的外緣**：列的左右沒有邊線，每一列下方有一條分隔線
- **卡片（profile、card、gallery）與表格的四周留白 16px**，放得下卡片的陰影。分組時，組的標題仍貼齊外緣
- **畫面寬時，列表置中並有最大寬度**，兩側留白：

| 畫面寬度 | 列表最寬 |
| --- | --- |
| 840px 起 | 700px |
| 1145px 起 | 1000px |
| 1545px 起 | 1400px |
| 2138px 起 | 2000px |

- **卡片之間的間距為 8px**，用於 profile、card，以及 gallery 的格與格之間
- **profile 與 card 的圓角為 12px**，gallery 為直角
- **卡片的陰影偏向右下**：向右 2px、向下 3px、模糊 6px，黑色 16% 不透明度。陰影往右下擴出約 8px，卡片之間的間距不小於此值
- **多選時，選取的列疊上一層主色淡底**，為主色 8% 不透明度
- **儀表板中選取的那一列**，左側有一條 3px 的主色細邊
- **儀表板中面板標示的列**（例如詳細面板顯示的列），左側有一條 3px 的細邊，為主色 40% 不透明度。同時為選取的那一列時，顯示選取的細邊
- **每一列的 ⋮ 選單與 App Bar 的 ⋮ 選單**：圖示與文字的間距為 20px，圖示與文字同樣深淺
- **分組的展開箭頭與標題之間的間距為 8px**，窄面板中也放得下標題
- **已指定但沒有圖片時的灰色方塊**，與圖片同樣大小

**deck**：
- 縮圖 48×48，圓角 4px
- 各位置皆為一行時，一列約 72px 高。有動作列時約 108px，多出一行 32px 的按鈕與 4px 的間距

**profile**：
- 圓形頭像 40×40
- 一張卡片約 68px 高

**card**：
- 第一層 64px 高：上下各 12px 的內距與 40×40 的頭像
- 第二層的大圖為 16:9，寬度撐滿卡片
- 第四層 48px 高：上下各 8px 的內距與 32px 的按鈕

**gallery**：
- 每一格固定為 3:4，圖片為正方形，上、左、右各留白 8px。圖片下方剩餘的高度為文字區，手機上約 50 至 60px，放得下標題與副標各一行
- ⋮ 按鈕位於文字區右下，距右緣與底緣各 2px。副標的右側留出 ⋮ 的寬度
- 每一欄至少 140px 寬：手機上為兩欄，畫面寬約 468px 起為三欄。平板與電腦依寬度自動增加欄數

**列數的小標籤**（分組標題與子表區塊的標題）：
- 高 20px，至少 22px 寬，圓角 10px，字級 0.75rem
- 底色為文字顏色的 10% 不透明度，隨主題切換

## 設計時須決定的事

- **版面**：五種之中選擇哪一種
- **各位置放置的欄位**：標題、副標、摘要、補充，以及圖片
- **條件式格式**：哪些情況下，哪些欄位改變顏色、字形或加上圖示
- **每一列的動作**：放置哪些，各自以圖示或文字呈現
- **分組**：依哪些欄位、分幾層、哪些列不再細分
- **搜尋、篩選與排序**：哪些欄位可以搜尋或篩選、可以排序，以及在抽屜中的先後。這張表預設的順序
- **FAB**：通常為新增。新增時是否預先帶入某些值，例如目前頁籤的狀態
- **App Bar 的動作**：通常為多選時對選取的列的動作
