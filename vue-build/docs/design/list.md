# 列表頁

一張表的資料逐列排開，用來瀏覽、找到某一筆，以及對多筆一次處理。點擊一列即進入該筆的詳細頁。

App Bar 裡有搜尋與排序，以及這一頁的動作；右下角的 FAB 通常為新增。

---

## 五種版面

每一列的呈現方式有五種。同一張表可以換用不同的版面，各位置要放置哪個欄位則另行指定。

| 版面 | 外觀 | 每一列的動作 | 適合 |
| --- | --- | --- | --- |
| deck | 連成一串的列，左側一張小縮圖，四個角各一個欄位 | 列的下方一排按鈕，靠右 | 一般的瀏覽，一列可看到較多欄位 |
| profile | 分開的卡片，左側圓形頭像，中間標題與副標 | 右側的 ⋮ 選單 | 以人或物為主體、資訊精簡的表 |
| card | 分開的卡片，上下四層：頭像與標題、大圖、標題與摘要、動作 | 第四層，左右各兩格 | 圖片與說明並重的表 |
| gallery | 方格排列，上方正方形圖片，下方標題與副標；手機上為兩欄 | 右下角的 ⋮ 選單 | 以圖片為主的表 |
| table | 表格，一列一筆、一欄一個欄位 | 無 | 同時比對多個欄位 |

### deck

- 左側的縮圖可省略；有指定但這一筆沒有圖時，留一塊同大小的空白
- 四個角：左上為標題（粗體），右上為副標，左下為摘要，右下為補充
- 每個角皆可不放欄位，不放的角不佔位置；放了欄位但這一筆沒有值時保留它的位置，各列因此對齊

### profile

- 左側的圓形頭像可省略，省略時標題往左靠齊；有指定但這一筆沒有圖時，留一塊同大小的空白
- 只有標題與副標兩行，過長時以省略號截斷
- 動作一律收在 ⋮ 選單中，只有一個動作時亦同

### card

由上而下四層，沒有放任何欄位的層整層不出現；放了欄位但這一筆沒有值時保留它的位置，大圖以灰色方塊佔位：

1. 圓形頭像，右側為標題與副標
2. 寬度撐滿卡片的大圖，比例固定為 16:9
3. 標題、副標與摘要，摘要最多三行
4. 動作，最多四格，前兩格靠左、後兩格靠右，可以留空格

第一層與第三層可以放相同或不同的欄位，例如第一層放建立者、第三層放名稱與金額。

### gallery

- 圖片為正方形，周圍留白；沒有圖片時以灰色方塊佔位
- 標題一行，佔滿寬度；副標一行，右側留給 ⋮ 選單
- 依由左往右、再由上往下的順序排列

### table

- 只用於比對欄位，沒有多選，也沒有每一列的動作
- 點擊一列進入詳細頁

---

## 如何選擇版面

- **沒有圖片的表**：deck；資訊較少、以名稱為主時可用 profile
- **以人或物為主體、需要一眼認出是誰**：profile
- **圖片與文字說明一樣重要**：card
- **圖片是主角，文字僅為標註**：gallery
- **要一次比對大量欄位**：table，但無法多選
- 同一張表在不同頁面可以用不同的版面，例如列表頁用 deck、儀表板的小面板中用 profile

---

## 分組

列表可以依欄位分成幾組，例如依年份，再依月份。

- **每一組有一條標題列**，標題後面以小標籤顯示這一組有幾筆
- **可以分好幾層**，每一層都可以收合；同一層一次只展開一組
- **某一層只有一組時**，該組固定展開、不能收合，例如篩選後只剩「2026年」
- **部分的列可以不再往下分**：例如「待處理」這一組底下不再細分，展開後直接列出各列
- **使用者選了排序時不分組**，整份列表依所選的方式排列

---

## 點擊與多選

- **點擊一列進入詳細頁**；按住修飾鍵或用中鍵點擊時，以新分頁開啟
- **長按一列進入多選**：每一列出現勾選的圓圈，被選的列加上主色的淡底；點擊改為勾選或取消
- **多選時 App Bar 換成這些選取的動作**，例如批次刪除，以及右上角的「取消」；搜尋與排序暫時隱藏，每一列的動作也隱藏
- **取消所有勾選、按「取消」、換頁或換頁籤時**，多選自動結束
- table 不支援多選

---

## 搜尋

- **按放大鏡後，整條 App Bar 換成搜尋列**，標題與動作暫時讓位；按搜尋列左側的返回鍵關閉
- **輸入時即時過濾**，比對的是文字欄位，以及關聯到的另一筆的名稱
- **以空白分隔多個詞時，每個詞都要符合**；以引號包住的幾個字視為一個詞
- 不分大小寫
- **換頁時搜尋列自動收起**，回到這一頁時恢復原本輸入的字並重新打開

---

## 篩選

- **篩選鈕在搜尋列的最右側**，有條件生效時以主色標示；按下後自右側滑出抽屜
- **抽屜分兩層**：
  - 第一層列出可以篩選的欄位；已設定條件的欄位，名稱下方以小字顯示目前的條件，右側有一個主色的圓點
  - 點一個欄位進入第二層填寫條件：選項類與是非的欄位為一列一個勾選框，數字、日期與時長為一個範圍（只填一邊亦可）
- **選項類與是非的欄位另有「(空白)」**，勾選後才保留沒有填值的列
- **選項只列出資料中實際出現過的值**
- **欄位之間的條件須同時成立；同一欄勾選多個值時，符合其中之一即可**
- **改了即時生效**，不需按套用；第一層的「清除」清掉這張表的所有條件，關閉搜尋時條件亦一併清除
- 抽屜開著時，畫面的其他部分都無法操作，須先關閉抽屜
- 同一頁有多張表時（頁籤頁或儀表板），抽屜上方多一排表的標籤，切換要設定哪一張表

---

## 排序

- **排序鈕在放大鏡右邊**，按下後由右側滑出與篩選同一個抽屜
- **一次只依一個欄位排序**：點一個欄位即依它排序，再點一次切換遞增或遞減，右側的箭頭顯示目前的方向
- **「清除」回到這張表預設的順序**；不是預設的順序時，排序鈕以主色標示
- 改了即時生效；重新整理頁面後回到預設的順序
- 文字中的數字依大小排序，例如「2」在「10」之前；選項類的欄位依選項定義的先後排序，不在選項中的值排在其後，是非的欄位否在前、是在後，關聯的欄位依另一筆的名稱排序；沒有值的列一律排在最後

---

## 設計時要決定的事

- **版面**：五種之中選哪一種
- **各位置放置哪個欄位**：標題、副標、摘要、補充，以及圖片
- **每一列的動作**：放置哪些、各自以圖示或文字呈現
- **分組**：依哪些欄位、分幾層、哪些列不再細分
- **搜尋、篩選與排序**：哪些欄位可以搜尋或篩選、可以排序，以及在抽屜中的先後；這張表預設的順序
- **FAB**：通常為新增；新增時是否預先帶入某些值，例如目前頁籤的狀態
- **App Bar 的動作**：通常為多選時的批次動作
